# Agent CLI parity

This inventory is based on the active parser and handlers in `composition/cli.rs` at the Agent CLI parity campaign's starting main (`73411840`). The old `apparent` command remains authoritative for commands not listed as implemented below. Agent work is owner-local TypeScript under `agent/`; it does not change installed routing.

## Local inspect contract

`apparent-agent inspect [BUNDLE|latest]` resolves only local bundle paths. Default text is regenerated from the validated `apparent.json` manifest, so absent or stale `summary.md` cannot hide current manifest semantics. `--stored-summary` explicitly prints bounded producer-authored text. `--json` writes the original manifest bytes unchanged; `--marks` and `--marks --json` retain the established Rust mark shape and ordering. `--transcript` and `--images` remain local conveniences. `--experiment agentContext` selects the richer event/mark timeline for this inspection only; a `true` value in `experiments.agentContext` in the existing config also enables it, and an explicit flag overrides a configured `false`. The default remains off and inspection never writes config. Unknown experiment names are accepted as Rust's repeatable option accepts them and have no Agent formatting effect. `--stored-summary` cannot apply this formatter and conflicts with that experiment option.

Inspection never fetches a URL, invokes Engine/native code, decodes media or changes bundle/config files. Manifest and explicit stored-summary reads are strict UTF-8, no-follow, regular-file reads capped at 64 MiB. Image listing validates safe relative references without opening image contents. The generated text retains local absolute bundle path, app/device/window context, app context values, notes, transcript, marks/events, available audio/transcript warnings, crop and image-quality warnings, and instructions to inspect visual files. agentContext uses timed words, clause snapping, keyframe ownership, settled interactions, window changes and context changes. WAV presence requires a bounded local no-follow read of a valid WAV header and first PCM8 or PCM16 sample; no decoding, encoding or native media execution occurs. Text is semantic; pictures remain bundle files.

## Acceptance and retirement boundary

The local inspection slice is accepted when the Agent owner suite, packed consumer install, and Rust-free TypeScript build all pass; current, legacy and producer-shaped synthetic fixtures match Rust output after substituting only the temporary bundle path; inspection leaves manifest/config bytes unchanged; and the built package works outside the checkout without Desktop, Rust or network access. The standalone skill command has no native OS boundary and does not select new `apparent` routing.

The legacy Rust command remains until every supported installed/package-manager consumer has moved and each command family's owner has accepted its replacement. Agent package publication, app command routing and donor deletion are separate campaign gates; a parity entry in this table is not evidence that those gates passed.

## Explicit offline native media installation

The standalone npm package includes `apparent-agent-install-local`, which
accepts a local Agent tarball, its trusted expected SHA-256, a complete native
media root, its trusted manifest SHA-256, and a fresh absolute prefix. It
supports Linux x64 only and requires Node 22.13+ plus existing npm. It verifies
the Agent archive before invoking `npm --offline --ignore-scripts`, checks the
installed Agent/SDK versions and media export, verifies every regular file,
mode and hash in the native inventory before and after copying, then requires
a media/1 handshake and confirmed worker close before writing a success
receipt. The full root (entry, worker, libraries, plugins and manifest) is
retained. The generated launcher sets the explicit media executable and a
private runtime path; it does not configure capture-v1 recording or global
`apparent` routing. Input archives and roots are never modified. Existing or
symlinked prefix paths are refused; failed installs leave a private partial
prefix without a success receipt. Same-UID processes share the trust boundary.
Manifest integrity is not provenance: callers must obtain both digests from a
trusted upstream admission/receipt. The documented 463 artifact pair is an
example and does not override current-tree admission/reuse requirements.

This install path does not add Connect, Mac media, capture, export, inference,
or maintenance support and makes no codec claim from its handshake. The
consumer continues to use the SDK for media frames/zoom; ordinary standalone
Node CLI inspection stays portable without an installed provider.

## Local synthetic demo

Demo generation is owner-local TypeScript and uses bundled pure-JS PNG encoding plus the Agent's shared annotation rasterizer. It writes only into a new owner-private directory, with mode-0600 assets and the manifest completion marker last; failure cleanup only unlinks paths created by that invocation. Default location follows the read-only capture-directory resolution; explicit output must be a fresh absolute `.apparent` path. Output includes a visible synthetic provenance marker and synthetic target labels. This is illustrative content, not evidence of recording or native media. `inspect`, saved-keyframe `frames`, and `zoom` consume the result locally without Engine, Desktop, provider, UI or network. `--clipboard` is a recognized truthful failure before output. Native clipboard parity remains blocked on a published native handoff route and platform proof.

## Zoom output and limits

`apparent-agent zoom` implements the local legacy selection contract: time-first parsing, first normalized timed-word phrase then transcript-segment fallback, a ¼-before moment window, mark-centered windows containing the full mark plus 500 ms, and endpoint-inclusive ordered samples capped at 48. Mark-number context uses the same structured mark entries and duplicate-number `--frame` disambiguation as Agent inspection. In saved mode it maps each frame by its exact manifest path to a retained full-frame counterpart and applies crop points normalized by the capture frame dimensions. If only autocropped `frames/` remain, the saved image is already cropped and Engine-annotated; zoom preserves it without a second crop/annotation and reports that a full frame is unavailable. Provider-decoded frames receive the nearest/focused crop and actual bundle ink/interaction rendering, including each stroke's optional exact `[r,g,b]` sRGB byte triplet for plain ink, pin fill and laser trail. Omitted RGB preserves existing style colors; malformed RGB is rejected before decode or output creation. Color alpha remains style-specific. The sidecar records deterministic row-major cell order, absolute source image refs, per-cell times, crop mapping and applied crop, mark and interaction context, source kind, annotation provenance and timed narration. The picture contains only image pixels with actual visual ink/interaction marks—no caption text.

Provider mode uses only the published media SDK for video decode and retains its configured failures/uncertain outcomes. A missing source video permits saved fallback even when provider paths are configured. Linux x64 native decode is available through the complete admitted runtime and explicit offline installer described above; focused H.264 consumer checks cover frames and zoom with that retained component pair. Current-tree artifact admission remains a separate gate. macOS native media decode is unavailable. The `zoom` command does not install or activate a provider and does not build from source or fall back to FFmpeg. Provider-absent mode composes actual PNG keyframes selected within the inclusive window and labels them `saved-keyframes` / `bundle-manifest`; timestamps stay at their actual manifest values and no dense-sampling claim is made. The package bundles pure-JS `pngjs` for bounded PNG decode/encode; this is image composition, not native video decode or proof. Interlaced PNGs are rejected before the decoder; aggregate input bounds are checked before any decode; decoding runs in a resource-limited worker with a deadline. Output is a fresh owner-private cache directory or a fresh explicit `--out` directory; sources are never overwritten. PNG inputs, dimensions, total bytes/pixels, output pixels, annotation work and frame count are bounded, and composition failure removes only its own incomplete output.

## Bundled standalone skill

`apparent-agent skill` writes `skills/apparent/SKILL.md` byte-for-byte to stdout, adding a final newline only if the packaged guide has none. It reads only that package-relative text file; it does not load config, locate bundles, launch Engine or access the network. The standalone guide teaches visual-first reading and the installed `apparent-agent inspect` commands. Its documented recording adapter remains unavailable without a future Engine recorder/media capability. This does not replace or change the legacy Rust `apparent skill` guide or its command routing.
