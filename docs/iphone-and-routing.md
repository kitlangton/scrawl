# iPhone sources, ScrawlKit ingest and dev-site routing

Read this before changing `src/phone.rs`, `src/delivery.rs`, `src/routing.rs`, `src/web.rs`, `src/sdk.js`, `Sources/ScrawlKit/` or the helper's phone capture. The delivery recovery rules are in `AGENTS.md` because they apply even when you aren't editing this code.

## iPhone sources (`src/phone.rs`, `helper/`)

- `scrawl-helper` (Swift, built by `build.rs` into `target/<profile>/`, copied and signed into `Scrawl.app/Contents/MacOS` by `install-app.sh`) does SpeechAnalyzer, CoreMediaIO/AVFoundation phone capture with the mirror window, and movie decoding. Swift was chosen over objc2 bindings because SpeechAnalyzer has no Objective-C surface and `objc2-av-foundation` is not in the lockfile.
- Picker discovery (`scrawl-helper devices`) reads the USB registry only: it is instant and never touches AVFoundation, so opening the picker can't raise a camera prompt or hang. The first time iPhone is chosen without Camera, Scrawl closes the picker and opens the onboarding window's Camera row instead of starting the mirror (whose prompt would land under the picker).
- Live capture: the mirror window's rect (global top-left points, streamed by the helper) is the telemetry target, so ink/laser/clicks normalize into phone coordinates; inputs are re-based onto the movie's clock (`recording.startedAt`) at finish. Keyframes are selected on 320 px candidates and re-decoded from the native video at a 1600 px long edge.
- ScrawlKit ingest (`ingest_recording`, `src/delivery.rs`): the Mac answers an upload only after the bundle is built and queued into OpenCode, or after the phone's `X-Scrawl-Wait` (default 25 s, max 45 s): `200 {"ok","delivered","state":"sent"|"queued"|"saved"|"processing","sessionTitle","error"?}`; a failed build answers 500 and forgets the recording so it can be sent again. Copies of one recording (LAN + Tailscale, HTTP + USB, keyed by `recordedAt`) wait for the first and get its outcome. A failed forward is `queued`: the bundle gets `.deliver.json` and the port owner retries it (15 s doubling to 30 min, for a day, then `.deliver-failed.json`); the phone never re-uploads for it, and retention skips the bundle. Over USB the Mac writes `<stamp>.delivery` (the same JSON) before `<stamp>.sent` (the session name, all older ScrawlKit reads). ScrawlKit's `IngestReply` treats a reply without `delivered` as sent. Tests swap the outside steps through `IngestHooks`; never post to a real session.
- Audio for transcription is always the movie's audio exported on the asset timeline (`scrawl-helper audio`). Do not feed a `.mov` straight to SpeechAnalyzer: `AVAudioFile` ignores the movie timeline and its word times drift (≈1.5 s late at 41 s on a phone recording).

## Dev-site routing (`src/routing.rs`, `src/web.rs`, `src/sdk.js`)

A Screen capture that ends with a browser in front (Window mode: the captured app) reads the tab URL with `osascript` (6 s cap, for the one-time Automation prompt) while the bundle is built, then picks a session: a live `/sdk.js` registration for the tab's origin (`data-session`, or `data-directory` → newest open root session there), else for a loopback URL the port's listener (`lsof`) → cwd → git root → newest open root session inside it (`session_for_directory`: the API's exact `directory` filter, then a newest-first `handoff::find_root_session` scan for subfolders that stops at that match's age and reads at most `ROOT_SEARCH_PAGES` pages; V2 `location.directory`). A known session ID is one `GET /api/session/{id}` (`handoff::get_session`). Routing never holds up the capture: it is copied and the island shows Completed as soon as the bundle is built, and the route acts when it arrives (`ScrawlCoordinator::route_arrived`), unless ✕ or Paste kept the capture first. Session reads share `routing::SESSIONS_BUDGET` (3 s, from the first request) through `handoff::api_get_within`, which talks HTTP directly to the local OpenCode V2 server (`service.json` in `$XDG_STATE_HOME/opencode` or `~/.local/state/opencode`, else `$OPENCODE_CONFIG_DIR` or `~/.config/opencode`, with `SERVER_CONNECT_TIMEOUT` 400 ms) instead of spawning `opencode2 api` per read. The log's `finish: copied at … · routed at …` line shows both times. The choice is written to `scrawl.json` `destination` and the summary's second line, then sent through `delivery::deliver` (same `.deliver.json` retries as iPhone). `recorded_destination` prefers a timeline's `session`, then `destination.session`. `/sdk.js` and `/web/*` on the ingest port skip the bearer check only for a loopback `Origin` from a loopback peer (`web::may_register`); `/web/registrations` needs the token. `scrawl route --url` prints the decision without sending; tests swap the outside steps through `routing::Hooks`. Off with `"autoSend": false`.

With `"experiments": {"smartRouting": true}`, `src/routing/smart.rs` and `src/routing/look.rs` decide instead, from more clues and with a confidence threshold; see `docs/routing.md`. Changes to the ladder above must keep `look::tests::the_ladder_policy_reproduces_route` passing.

## Agents on another machine (`src/handoff.rs`)

When `"agentHost"` (`SCRAWL_AGENT_HOST`) is set in `~/.config/scrawl/config.json`, `handoff::sync_bundle_to_with` copies each finished bundle to `"agentPath"` (`SCRAWL_AGENT_PATH`, default `"~/.scrawl/captures"`) on that SSH host in two stages:

1. **Foreground (`tar | ssh`):** unpacks `contact-sheet.png`, `frames/*.png`, `scrawl.json`, and `summary.md` into `$d/<id>.scrawl`, touches `.media-pending` when heavy media will follow, and prints `cd "$d" && pwd` so the Mac learns the expanded remote path (for example `/home/exedev/.scrawl/captures/<id>.scrawl`). Scrawl records `{host, path}` in `.remote.json` inside the local bundle and rewrites `summary.md` to use the remote path.
2. **Background (`tar | ssh`):** streams `recording.mp4`/`.mov`, `audio.wav`, `frames-full`, and `contact-sheet-full.png` into a staging folder on the remote host, moves them into the bundle, and removes `.media-pending` (holding `.media-sending` locally until done).

`handoff::shown_bundle_dir` returns the synced path from `.remote.json`, so `summary_markdown`, `copy_bundle_to_clipboard` (`⌘V`), `paste_bundle_image_and_text` (`⌥⇧V` in a terminal), and `send_bundle_to_session` (`file://` URI and `scrawl zoom` hint) all hand the agent paths that exist on the remote host. Tests swap the SSH transport through `handoff::SyncHooks` (`remote_tar`, `background_heavy: false`) and never open real network connections.
